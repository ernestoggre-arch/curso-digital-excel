Caso 1. Control de Inventarios

Una empresa requiere controlar sus productos mediante códigos, cantidades, entradas y salidas automáticas. El participante deberá elaborar una hoja de cálculo capaz de identificar productos faltantes y existencias mínimas.

Caso 3. Reporte de Ventas

Actividad Descargable de Excel

Práctica Profesional: Control Administrativo Empresarial

El participante deberá desarrollar un archivo de Excel profesional orientado a la capacitación de personal administrativo de nuevo ingreso.

Objetivo de la actividad

Aplicar las herramientas aprendidas durante el curso mediante el desarrollo de un sistema administrativo funcional utilizando Microsoft Excel.

Instrucciones

  1. Crear una hoja de cálculo llamada “Control Administrativo”.
  2. Registrar 15 empleados con:
    • Nombre completo
    • Puesto
    • Área
    • Salario
    • Fecha de ingreso
  3. Aplicar formato profesional a la tabla.
  4. Utilizar funciones:
    • SUMA
    • PROMEDIO
    • MAX
    • MIN
    • SI
  5. Generar una tabla dinámica.
  6. Crear una gráfica de salarios por departamento.
  7. Agregar filtros automáticos.
  8. Diseñar una portada profesional.

Entregable

El participante deberá entregar el archivo final en formato .xlsx.

Actividad Integradora Final

Como actividad final, el participante deberá desarrollar un sistema administrativo en Excel que integre los conocimientos adquiridos durante el curso.
